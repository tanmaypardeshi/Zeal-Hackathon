# React-Flask with JWT auth

### Steps to run the project:

* **Requirements:**<br>
  1. python: version 3.8.x
  2. npm: version 6.14.x
  3. node: version 12.16.x
  4. pip and pipenv
 
* **Steps:**
  1. Clone the repository using<br> **git clone https://github.com/tanmaypardeshi/React-Flask.git**
  2. Use command **pipenv shell** to activate pipenv.
  3. For the first time, use **pipenv install** to install all dependencies<br>
  This will only be for the first time to install the packages.
  4. Navigate to the frontend folder and run **npm i** for the first time to install all javascript dependencies for React.
  5. To run the flask server use **python run.py** in the main project directory.
  6. Navigate to the frontend folder and run **npm start** to start development server and use the platform while keeping 
  the flask server running as well
